# 截图与素材清单

本目录用于存放分享会用到的截图/图示素材。当前交付版本未嵌入真实图片，演示文稿中以 `[截图位: ...]` 占位，正式分享前请按本清单补齐。

## 文件命名约定

- 全部使用小写英文 + 短横线：`p05-flow.png`、`p06-spec-output.png`……页码与 `01-演示文稿.md` 的页编号对应。
- 图片建议尺寸：宽度 1600px（适配 Slidev 默认 1280 视口的 2x 清晰度），格式 PNG/JPG，单张不超过 1MB。
- 需要圈注/高亮的地方直接在图上标（红框、箭头、文字标签），不要只给原图让听众自己找。

## 截图通用脱敏 checklist

- [ ] URL 栏：`?token=...`、`?session=...`、临时预发域名，一律裁掉或打码
- [ ] Cookie/Authorization Header：永不入镜
- [ ] 个人信息：姓名、邮箱、工号、头像，按需打码
- [ ] 内部系统：内部域名、内网 IP、未发布的功能名，统一打码
- [ ] 工单/任务 ID：其他无关任务的 ID 打码，本次分享任务的 ID 可保留
- [ ] 数字水印：如果截图平台自带水印，确认不含个人信息即可
- [ ] 第三方/友商产品：如果借用别站截图做反面案例，打码处理、避免直接点名

## 不想截图怎么办？

如果不想/不方便补真实截图，也可以：
- 直接删除演示稿里对应页的 `[截图位: ...]` 行，用文字讲完；
- 或用简单的 Mermaid 图/表格/示意图替代；
- 分享是内部分享，真诚比 PPT 精美更重要。
