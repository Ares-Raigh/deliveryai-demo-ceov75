## 本地演示

```bash
# 在仓库根目录下执行
npx slidev docs/sharing-ai-board/01-演示文稿.md
```

首次运行 Slidev 会提示安装依赖，装完自动在 `http://localhost:3030` 起演示服务。
若要导出静态 PDF/HTML，可使用 `npx slidev export` 或 `npx slidev build`，具体见 Slidev 官方文档。
